# SolarTech Knowledge Base

This knowledge base contains structured information about **SolarTech**, a fictional company producing solar-related products.
The content is designed to be easily chunked and embedded into a vector database for semantic search and Q&A.

## Structure
- Company overview
- Product catalog
- Installation guidelines
- Maintenance & troubleshooting
- Safety & compliance
- Warranty & support
- FAQs
- Glossary

Each file uses clear headings and concise sections suitable for vectorization.
